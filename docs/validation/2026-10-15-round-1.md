Status: code and automated checks verified locally; release acceptance incomplete. The user explicitly deferred mobile acceptance on 2026-10-15. No new npm version or GitHub release has been published for this iteration.

Baseline: `4693c0833ba5f6c705929d7a7d975d9dfdd8a12e`, package `0.2.0`, Node `22.23.2`, pnpm `11.25.0`, OpenCode host/SDK `2.0.29`. GitHub and npm both reported `v0.2.0` / `0.2.0` at the start; these are existing releases, not evidence that this patch is published.

## Workflow and priorities

The installed plugin loads in a registered V2 shared service and restricts Telegram access using configured chat IDs. Commands create/switch/rename sessions and select session-scoped models, reasoning levels, agents, and languages. A chat lease serializes prompts; the V2 prompt is durably admitted and awaited while matching events drive thinking, answer drafts, and compression feedback. Final answer chunks and a separate context footer persist. Images use temporary forks; permission requests have approval callbacks. Voice input remains unsupported, and V2 LSP status remains unavailable.

This iteration prioritizes cancellation correctness and preserving generated data over new commands or visual redesigns. Existing command, image, permission, language, and packaging coverage remains part of the regression suite.

## Problems reproduced and changes

| Priority | Reproduction | Change and evidence |
| --- | --- | --- |
| P1 | Cancel a request before it has attached an execution session while an older bound session is busy. The old implementation queries and interrupts the older session. | Preparation cancels only the local lease. Regression forbids both remote calls. Remote calls in this specific fixture decrease from 2 to 0; no general latency or throughput gain is claimed. |
| P1 | Replace a request during an asynchronous cancellation status lookup, or attach a session using a disposed lease. | Capture and recheck request identity for both button and command cancellation; ignore session attachment from a stale lease. |
| P1 | Status lookup or interruption fails while a local prompt is waiting. | Abort the original local lease in `finally`; propagate the remote failure rather than claiming the server stopped. Both SDK operations use the configured poll-request deadline. An actual native timeout-signal test uses a stalled operation. |
| P1 | A provider returns text and an assistant error. Previously, final delivery overwrites the generated answer with the error. | Retain text, persist any streamed answer, and show the localized error separately. A new fixture fails before the patch and passes afterward. Empty-response fallback behavior remains covered. |
| P2 | A non-formatting Telegram 400 error enters a literal-text fallback. | One predicate recognizes explicit formatting rejection across prompts, drafts, thinking, model menus, help, and permission requests. Network failures and unrelated 400s do not qualify. |
| P2 | Production dependency audit reports two advisories for locked `picomatch@4.0.3`. | Refresh only this transitive dependency to `4.0.7`; keep the OpenCode SDK pinned to `2.0.29`. Production audit after the change reports zero vulnerabilities. |

The first five cancellation/lifecycle regressions produced 5 failures before editing and 0 afterward. Additional coverage checks bound-session cancellation races, request timeouts, formatting classification, and provider-error answer preservation.

## Bounded security/performance reproduction

Using Node `22.23.2`, compare separately installed `picomatch` versions `4.0.3` and `4.0.7`. Compile `picomatch("+(a|aa)")` once, then time three matches of `"a".repeat(37) + "!"` with `performance.now()`, asserting each result is false. Run each version in a separate child process with a 5-second deadline. The non-matching input is 38 characters long.

| Version | Match durations, milliseconds | Median |
| --- | --- | --- |
| 4.0.3 | 191.949, 180.869, 178.613 | 180.869 |
| 4.0.7 | 0.011708, 0.002792, 0.002250 | 0.002792 |

Four ordinary positive/negative matching cases passed in both versions: `*.ts` against `app.ts`/`app.js`, `src/**/*.ts` against `src/bot/index.ts`, and `+(foo|bar)` against `foobar`. A separate positive test exposed a compatibility change: `+(a|aa)` matches 37 `a` characters in 4.0.3 but is treated literally in 4.0.7. The initial parity assert therefore failed and was retained as a finding rather than hidden. The patch avoids pathological regex matching by changing interpretation of this unsafe pattern; this is a security hardening result, not a semantics-preserving Telegram speedup. The real host integration remains the compatibility gate for supported plugin flows. JSON timings are in `picomatch-benchmark.json` alongside the package receipt.

## Real Telegram desktop checks

- Reloaded the configured shared host and loaded the project location. A real prompt produced a ten-row, three-column sorting comparison and `DESKTOP_R1_OK`, with a separate thinking control and context footer. The screenshot was visually inspected in this chat.
- A real long-running model request was cancelled using Telegram `/cancel`; the desktop showed the abort acknowledgement and terminal aborted reply, and the host had no active execution afterward. This run was cancelled before answer text appeared, so it does not establish live stopped-answer preservation.
- A controlled provider-error fixture used the current handler and real Telegram API. The desktop displayed the complete table, `DESKTOP_R1B_PARTIAL_PRESERVED`, and a separate Chinese provider error. The handler callback expanded the same persisted thinking message; the expanded body was visually inspected. This fixture validates delivery and rendering, not a naturally occurring provider outage.
- The first standalone Node harness attempt failed with `ECONNRESET` on its initial send; it was not retried ambiguously and is retained as failed evidence. A separate, distinctly marked fixture used native fetch after a successful read-only connectivity check and passed. The normal Bun-hosted bot's real prompt and cancellation checks used its existing transport.
- Native clicking of Telegram's inline text links returned macOS `AXError.notImplemented`, including after raising the window. The callback/API path and expanded rendering passed; physical expand/collapse and Stop-button clicks remain unverified.
