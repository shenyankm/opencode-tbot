## 性能边界

`lifecycle-baseline.json` 为 3 轮基线，`lifecycle-10-rounds.json` 为 10 轮重复生命周期实验。20 聊天、200 请求组：首次反馈插件等待 p95 约 0.52 ms，本地取消释放 p95 约 11.73 ms，事件循环延迟 p95 约 11.18 ms，结束活动请求为 0。

Telegram RTT 固定模拟 1 ms，provider 每 180 ms 输入一个片段。API 次数是夹具观察到的调用，写盘字节是实际临时文件写入量；取消指标从本地取消触发开始，不包含真实 Telegram 回调传输或远端 interrupt 确认。堆变化未经强制 GC，不能用来断言没有泄漏。该实验约 49 秒，没有真实公网时延、数小时运行或重复真实宿主 reload 的稳定性证明；也没有宣称相对旧版本提速。
